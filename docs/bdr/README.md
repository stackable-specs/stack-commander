# Behavior Decision Records — typescript-bun stack

Behavior contracts for the typescript-bun stack, governed by
[`docs/specs/practices/bdr.md`](../specs/practices/bdr.md). Each BDR captures a
single capability the CLI agrees to uphold, with acceptance criteria a
black-box observer can confirm.
